# skin-cancer-detection
# 🧠 Skin Cancer Detection Using CNN

This project uses Convolutional Neural Networks (CNNs) to classify skin lesion images as **benign** or **malignant**. It aims to assist in early skin cancer detection through deep learning techniques using Keras and TensorFlow.

## 🚀 Features

- CNN-based image classifier for skin cancer detection
- Real-time image augmentation using Keras `ImageDataGenerator`
- Binary classification: Benign vs. Malignant
- Training and validation accuracy/loss visualization
- Built using TensorFlow/Keras and Matplotlib
